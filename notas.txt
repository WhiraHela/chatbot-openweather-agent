O QUE O PROJETO FAZ ATE AGORA
1. Sobe uma API Go em localhost:8080.
2. Consulta a OpenWeather usando chave no .env.
3. Expõe /weather para clima atual.
4. Expõe /forecast para previsão de 1 a 5 dias.
5. Trata cidade com acento usando encode no frontend e QueryEscape no backend.
6. Retorna JSON limpo para ser consumido pelas tools.
7. Define duas tools LangChain em TypeScript.
8. As tools chamam os endpoints Go.
